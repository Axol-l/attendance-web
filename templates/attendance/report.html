报表内容

Sheet1「考勤处理数据1」—— 每日明细：逐人逐日的 打卡时间与结果、班次、迟到/早退时长、上下班缺卡次数、当月加班合计。 同一人的姓名、部门、职位与统计列纵向合并；请假/出差/迟到/缺卡/外勤/ 外出按状态着色，周末日期标红。

Sheet2「考勤统计2」—— 月度汇总：序号、姓名、部门、 出勤（应出勤 / 出勤打卡 / 实际出勤）、各类请假天数、缺勤 （迟到分 / 早退分 / 旷工天 / 上下班忘打卡次数）、加班小时， 以及备注与员工签字栏。「实际出勤」保留 Excel 公式，可在表内继续计算。

口径说明
  • 应出勤：取自规则配置的 {{ rule.monthly_standard_days }} 天。
  • 出勤打卡：源文件「出勤天数」按月累计。
  • 实际出勤：= 出勤打卡 − 事假（Excel 公式）。
  • 加班：Σ max(0, (当日工作时长 − {{ rule.standard_work_minutes }}) ÷ 60) {% if not rule.clamp_negative_overtime %} —— 当前规则未截断负值，报表会与历史口径不同 {% endif %}。
  • 请假：{% if rule.exclude_rejected_leave %}只统计审批结果为「同意」的记录，{% else %} 当前未排除未通过的记录，{% endif %} 按「开始时间」归属月份，天与小时统一折算。
